Ce que contient l'édition complète

Ce qui est vérifié, pas promis

  • Installation vérifiée sur une base Odoo 19 neuve : aucune erreur, aucun avertissement de vue.
  • Contrastes texte / fond mesurés au niveau AA de la WCAG 2.1 sur tous les couples livrés.
  • Aucune dépendance Python ou JavaScript externe. Rien n'est chargé depuis un serveur tiers.
  • Toutes les images sont générées par programme : dégradés, formes géométriques, compositions typographiques. Aucune photographie sous licence.
  • Aucun contenu de démonstration ne cite d'entreprise, de marque ou de personne réelle.

Ce que ce thème ne fait pas

Autant le savoir avant l'achat qu'après.

  • Les blocs sont du contenu éditable : le portfolio et les tarifs ne lisent aucune donnée de l'ERP.
  • Le carrousel de témoignages n'affiche pas d'avis vérifiés : c'est un gabarit à remplir.
  • Le mode sombre assombrit les images par filtre CSS ; il ne fournit pas de visuels alternatifs.

Dépend de l'édition gratuite, qui reste gratuite. Vous ne payez que les blocs supplémentaires.
